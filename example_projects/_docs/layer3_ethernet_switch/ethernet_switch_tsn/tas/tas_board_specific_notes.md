# MCK-RA8T2 – Board-Specific Guide

## Specific Connections

| Status Pin | MCU Pin (Connector) |
|---|---|
| `ET_TAS_STA0` | P515 (CN4-P25) |
| `ET_TAS_STA1` | P514 (CN4-P24) |
| `ET_TAS_STA2` | P509 (CN4-P19) |
| `ET_TAS_STA3` | P413 (CN6-P09) |

**Note:** This pin mapping is taken from the gPTP + TAS multi-node notes for this same
MCK-RA8T2 board. Confirm the pin and connector numbering against the board schematic before
relying on it for a new bring-up.

## Hardware Configuration
None — this EP runs with the board in its default configuration and does not require any
configuration switch changes.

**Note:** This was not verified against the MCK-RA8T2 user manual; confirm the board's default
switch settings before publishing this guide.
