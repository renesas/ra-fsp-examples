# Board-Specific Guides

## RA8T2-MCK

### Additional Hardware
* None

### Specific Connections
* Connect **Port 1** of the **Sender** RA8T2-MCK board directly to **Port 1** of the **Receiver** RA8T2-MCK board using an Ethernet cable.
* Connect the USB debug port of each board to the host PC.

### Special Notes
* None
