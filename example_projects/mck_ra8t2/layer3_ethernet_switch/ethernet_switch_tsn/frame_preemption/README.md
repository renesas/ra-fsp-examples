# Frame Preemption Example Project

This example demonstrates IEEE 802.3br / 802.1Qbu **Frame Preemption** on the RA MCU using the internal Layer 3 Switch (L3 Switch). The example consists of two separate projects that run on two the RA boards connected back-to-back over Ethernet.
