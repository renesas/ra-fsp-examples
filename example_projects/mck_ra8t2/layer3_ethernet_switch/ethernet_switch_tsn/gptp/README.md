# Generalized Precision Time Protocol (gPTP) Example Project

This example project demonstrates IEEE 802.1AS (gPTP) time synchronization across a scalable multi-node Ethernet network built from Renesas RA MCUs. Every node in the chain disciplines its hardware clock to the same grandmaster.
