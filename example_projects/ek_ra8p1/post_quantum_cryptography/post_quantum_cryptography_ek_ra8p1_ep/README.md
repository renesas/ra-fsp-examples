# Post Quantum Cryptography (PQC) Example Project

The project demonstrates the basic functionality of Post-Quantum Cryptography (PQC) on Renesas RA MCUs using the PSA Crypto API and Renesas FSP. All cryptographic operations are performed through the PSA Crypto API with underlying Mbed TLS library support.
